## Context

pokemon.com is behind DataDome. Plain `fetch`, even with Chrome-like headers, receives a 927-byte interstitial with a JavaScript challenge instead of the real HTML. Headless Chromium is also detected. Bun on Windows has a subprocess bug where `chromium.launch()` hangs; Node (via tsx) works fine.

## Decision

Use Playwright with `headless: false` and `--disable-blink-features=AutomationControlled`, plus a `navigator.webdriver` override. Run the scrape command with `bunx tsx` (not `bun`) on Windows. Block images/fonts/media via route interception to keep run time manageable (~10 min for a 103-card set × 6 locales).

## Consequences

- First run downloads the full Chromium (~200MB).
- Scrapes open a visible browser window the user can watch.
- The rest of the CLI runs under `bun` fine; only the `scrape set` command requires `tsx`.
